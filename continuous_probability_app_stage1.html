Probability in real industries

Continuous probability distributions describe measurements and waiting times that can take many possible values. This application connects the theory to three beginner-friendly industry examples.

Module 01 · Manufacturing

Normal Distribution — Manufacturing Quality Control

Industry problem: A factory manufactures metal shafts. Their diameters vary slightly around a target value. Quality engineers use the normal distribution to estimate how many products fall within acceptable specification limits.

Illustrative input parameters

  • Target / mean diameter: μ = 10 mm
  • Standard deviation: σ = 0.05 mm
  • Lower specification limit: 9.90 mm
  • Upper specification limit: 10.10 mm

Mathematical model

X ~ N(μ, σ²)

The normal curve is symmetric around the mean μ.

Interactive calculation

Input controls and probability calculations will be implemented in Stage 2.

Dynamic visualization

The bell-shaped curve and shaded acceptable / defective regions will appear here in Stage 2.

Interpretation of results

The completed module will explain the acceptable production percentage and the expected percentage of defective shafts in simple language.

Module 02 · Cloud computing

Exponential Distribution — Cloud Request Inter-arrival Time

Industry problem: A cloud service receives requests over time. The exponential distribution can model the waiting time between requests when arrivals follow a constant-rate Poisson process.

Illustrative input parameters

  • Arrival rate: λ = 12 requests per minute
  • Time threshold: t (seconds)

Mathematical model

f(t) = λe−λt, t ≥ 0

The rate and time units must be consistent.

Interactive calculation

Arrival-rate and time inputs, probabilities, mean, and variance will be implemented in Stage 3.

Dynamic visualization

The exponential density curve and selected probability region will appear here in Stage 3.

Interpretation of results

The completed module will explain waiting-time probabilities and the memoryless property. Inter-arrival time is the time between requests, not server response time.

Module 03 · Warehouse operations

Central Limit Theorem — Warehouse Processing Time

Industry problem: A warehouse processes many orders. Individual processing times may vary, but the Central Limit Theorem helps explain how the average processing time behaves across repeated samples.

Model parameters

The sample size, population mean, and population standard deviation will be configurable when this module is implemented.

Mathematical model

Z = (X̄ − μ) / (σ / √n)

For sufficiently large samples, the sample mean is approximately normal under the usual CLT conditions.

Interactive calculation

Sample inputs and calculations will be implemented in a later stage.

Dynamic visualization

A sampling-distribution visualization will be added in a later stage.

Interpretation of results

The completed module will explain what the sample mean tells a warehouse manager about typical order-processing time.
